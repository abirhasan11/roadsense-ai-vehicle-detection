## ⚡ The Vision

The rapid commercial growth of Autonomous Vehicles (AVs) is transforming urban mobility, yet it exposes critical flaws in current infrastructure. **RoadSense AI** tackles three major industry gaps:

1. **Black-Box AI Decisions:** Decoding opaque vehicle decision-making during split-second scenarios.
2. **Missing Predictive Analytics:** Foreseeing and preventing collisions before they happen using proactive urban risk assessment.
3. **Inaccessible Interfaces:** Democratizing highly technical researcher tools for citizen contributors and safety auditors.

By capturing live hardware profiling from roof LiDAR domes and bumper radars, RoadSense AI translates raw environmental data into human-readable insights using **Explainable AI (Grad-CAM XAI)**.

## 🚀 Key Features

### 🎥 Live Camera & Sensor Integration
- **Webcam Streaming:** Seamless real-time device camera integration via `navigator.mediaDevices`.
- **Split-Screen Compare:** Side-by-side visualization of raw optical feeds vs. AI/LiDAR overlay data.
- **Snapshot & Upload:** High-performance Canvas-based capture and multi-format gallery support.

### 🧠 Real-Time XAI Simulation
- **Live Scanner Mode:** Continuous 1.5-second polling intervals for real-time edge processing.
- **Grad-CAM Saliency Maps:** Visualizing neural activation zones to explain *why* the AI made a decision.
- **Predictive Warnings:** Animated convergence timeline SVG charts and proactive traffic safety alerts.

### 📈 History & Urban Analytics
- **Granular Logs:** Track historical data including localized LiDAR point density metrics.
- **Urban Insights:** City-wide AV density insights visualized on an interactive vector map.
- **Export Ready:** One-click JSON and PNG export capabilities for researchers and engineers.

### ♿ Accessibility & Community
- **Voice-Guided Auditing:** Screen-free read-aloud functionality powered by the Web Speech API (`speechSynthesis`).
- **Multilingual Support:** Full interface internationalization (English & Bengali).
- **Multisensory Feedback:** Dual-tone Web Audio cues and haptic vibration feedback.
- **Citizen Gamification:** Earn XP levels and achievement badges for contributing to road safety.
